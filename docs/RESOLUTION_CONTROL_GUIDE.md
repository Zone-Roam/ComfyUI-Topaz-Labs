# 🎯 Topaz Labs 分辨率控制指南

## 📋 问题分析

### 🔍 发现的问题
- **设置**: 1280x1536 或 1280x1024
- **实际输出**: 2560x1440 (无论如何设置)
- **原因**: Proteus 模型有自己的智能放大逻辑

### 💡 根本原因
根据 [Topaz Labs 官方文档](https://docs.topazlabs.com/video-ai/filters/enhancement)：

1. **Proteus 模型特性**:
   - 是**通用增强模型**，主要用于**放大和细节增强**
   - 有自己的**智能放大算法**
   - 会根据输入质量自动选择最佳放大倍数

2. **智能放大逻辑**:
   - 输入: 1280x720 (720p)
   - 模型判断: 2x 放大最佳
   - 输出: 2560x1440 (1440p)
   - **忽略用户设置的具体分辨率**

## 🛠️ 解决方案

### 方案1: 使用不同的模型

#### 1. Nyx 模型 (保持原分辨率)
```python
model = "nyx-3"  # Nyx General - 主要用于降噪
```
- **特点**: 在 1x 模式下保持原分辨率
- **适用**: 想要降噪但不放大的情况
- **输出**: 1280x720 (保持原分辨率)

#### 2. Artemis 模型 (平衡增强)
```python
model = "ahq-12"  # Artemis High Quality
```
- **特点**: 平衡的降噪和锐化
- **可能**: 有更好的分辨率控制
- **适用**: 高质量输入的细节增强

#### 3. Rhea 模型 (4x 放大)
```python
model = "rhea-1"  # Rhea General - 4x upscaling
```
- **特点**: 专门用于 4x 放大
- **输出**: 5120x2880 (4x 放大)
- **适用**: 需要大幅放大的情况

### 方案2: 理解模型行为

#### Proteus 模型的放大规律
根据文档，Proteus 会根据输入分辨率自动选择放大倍数：

| 输入分辨率 | 自动放大倍数 | 输出分辨率 |
|-----------|-------------|-----------|
| 480p (854x480) | 4x | 3416x1920 |
| 720p (1280x720) | 2x | 2560x1440 |
| 1080p (1920x1080) | 1.5x | 2880x1620 |
| 1440p (2560x1440) | 1x | 2560x1440 |

# 在 topaz_video_nodes.py 中

## 🎯 推荐使用策略

### 1. 保持原分辨率 + 质量提升
```python
model = "nyx-3"  # Nyx General
output_width = 0   # 保持原宽度
output_height = 0  # 保持原高度
```

### 2. 适度放大 + 平衡增强
```python
model = "ahq-12"  # Artemis High Quality
output_width = 1920   # 1.5x 放大
output_height = 1080
```

### 3. 大幅放大 + 细节增强
```python
model = "rhea-1"  # Rhea General
output_width = 0   # 让模型自动 4x 放大
output_height = 0
```

### 4. 针对特定内容类型
```python
# 动画/CG 内容
model = "ghq-5"  # Gaia High Quality

# 人脸增强
model = "iris-3"  # Iris General

# 老旧视频修复
model = "dtv-4"  # Dione TV
```

## 📊 模型对比表

| 模型 | 主要用途 | 放大特性 | 适用场景 |
|------|---------|---------|---------|
| **prob-4** | 通用增强 | 智能 2x 放大 | 大多数视频 |
| **nyx-3** | 降噪 | 保持原分辨率 | 高分辨率降噪 |
| **ahq-12** | 平衡增强 | 适度放大 | 高质量输入 |
| **rhea-1** | 细节增强 | 4x 放大 | 精细细节提升 |
| **ghq-5** | CG/动画 | 适度放大 | 动画内容 |

## 🔧 实际操作建议

### 1. 如果想要精确控制分辨率
- 使用 **Nyx** 模型保持原分辨率
- 然后用其他工具进行后期缩放

### 2. 如果想要最佳质量
- 让 **Proteus** 自动选择最佳放大倍数
- 接受 2560x1440 的输出

### 3. 如果需要特定分辨率
- 使用 **Artemis** 或 **Nyx** 模型
- 在后期处理中调整到目标分辨率

## 💡 总结

**Topaz Labs 的 AI 模型优先考虑质量而不是精确的分辨率控制**。每个模型都有自己的"最佳实践"放大倍数，这是基于大量训练数据得出的最优结果。

如果你需要精确的分辨率控制，建议：
1. 选择合适的模型（如 Nyx 保持原分辨率）
2. 在后期处理中调整到目标分辨率
3. 或者接受 AI 模型的智能选择，通常质量会更好

这就是为什么专业的 AI 增强工具通常不提供完全自由的分辨率设置 - 因为 AI 模型知道什么样的放大倍数能产生最佳效果！
